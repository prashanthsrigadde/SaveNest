SaveNest V4 — Automatic Smart Organization
===========================================

This build fixes automatic category assignment and prevents a manual category choice from being overwritten.

When you share or paste a link, SaveNest attempts to obtain available shared/page metadata, then automatically creates:
- Source title (when available; otherwise a sensible fallback)
- SaveNest title
- SaveNest reminder
- Category
- Subcategory

You do not need to fill source title, description, category or subcategory just to save a link. The detected category is stored with the item. You can still edit the saved item later.

Travel is now a first-class category with Places, Trip Ideas and Tips subcategories.

Important: Instagram/YouTube may restrict metadata access from a static browser app. If the platform does not expose title/caption metadata, SaveNest uses share text, URL clues and its built-in rules to create the best available organization instead of inventing unavailable details.
