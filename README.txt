SaveNest V2
===========

Premium category-first redesign.

Features:
- Category-first home screen
- Visual category cards with saved counts
- Recently Saved section
- Full Library
- Favorites
- Search
- Notes
- Edit / Open
- Sorting
- Backup / Restore
- Custom categories
- Instagram / YouTube / web link detection
- PWA install + Android Share Target support

V2 keeps the V1 localStorage keys so existing V1 data can remain available on the same browser/device.

SaveNest stores links, not copies of Instagram/YouTube videos.
